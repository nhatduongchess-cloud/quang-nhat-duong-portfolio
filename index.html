Pipeline lái tự động end-to-end trong trình mô phỏng CARLA: nhận thức đa cảm biến → hợp nhất cảm biến (sensor fusion) → máy trạng thái an toàn (phanh khẩn cấp AEB + tránh né chuyển làn), kèm khung L3 kiểu “DRIVE PILOT” (ODD/MRM) và bộ điều khiển tốc độ học tăng cường — xây dựng với ưu tiên kỹ thuật kiểm thử được, an toàn trên hết. Mã nguồn trên GitHub ↗

  • Hành lang phanh LiDAR không cần hiệu chuẩn → phanh cho mọi vật cản trong làn bất kể YOLO có nhận dạng hay không; máy trạng thái NORMAL→FOLLOW→EVADE→EMERGENCY_BRAKE

ByteLoop — Electrostatic TRWP Capture System for EVs
May 2026 – Present

Hệ thống thu gom hạt bụi mài mòn lốp/đường (TRWP) tĩnh điện gắn trên bánh xe cho xe điện, xây dựng quanh pipeline dữ liệu real-time từ cảm biến đến cloud — theo mô hình kiến trúc tương tự các stack nhận thức của xe tự hành và hệ thống telematics đội xe quy mô lớn. Bộ điều khiển biên ESP32 thực hiện sensor fusion (load cell + giám sát hệ thống điện áp cao), truyền telemetry qua MQTT lên backend cloud để lưu trữ và phân tích chuỗi thời gian.

  • Sensor fusion & edge computing — thu thập, xử lý dữ liệu real-time trên ESP32
  • Real-time data streaming — pipeline telemetry MQTT từ thiết bị gắn trên xe lên cloud
  • Big data infrastructure — backend Supabase cho lưu trữ time-series, mô hình hóa quan hệ và phân tích quy mô đội xe
  • Fleet-scale data strategy — thiết kế cho pilot đa xe của Green SM, hướng tới bảo trì dự đoán và bản đồ nhiệt ô nhiễm
  • Data-driven product design — lớp ứng dụng Flutter tiêu thụ dữ liệu đã xử lý để tạo insight cho người dùng

Neural Voice Console
Feb 2026 – Present

Xây dựng pipeline speech-to-text và dịch đa ngôn ngữ chạy hoàn toàn local — không cloud, không API key, không chi phí vận hành, chỉ dùng các mô hình mã nguồn mở chạy trên máy cá nhân. Stack: FastAPI backend + frontend HTML/CSS/JS tùy chỉnh, dùng HuggingFace Whisper để phiên âm (Việt, Anh, Đức).

  • Fine-tune LoRA adapter trên ~4.000 mẫu audio tiếng Việt (6,5 giờ) — tăng độ chính xác từ 87,4% lên 94,3%, adapter chỉ 18MB (so với mô hình gốc 1,5GB)
  • Tích hợp NLLB-200 của Meta cho dịch VI↔EN↔DE (38,4 BLEU cho VI→EN)
  • Xây dựng lớp hậu xử lý phát hiện hallucination, chấm điểm độ tin cậy, trích xuất từ khóa và tóm tắt — không cần LLM API. Phát hiện ~12% đoạn audio nhiễu là hallucination, khôi phục output sạch ở 91% trường hợp qua retry
  • Đoạn clip 60 giây phiên âm trong ~4,2s trên CPU; fine-tune LoRA đầy đủ mất 3,5 giờ trên một RTX 3060
  • Hỗ trợ MP3/WAV/M4A/WEBM/OGG tới 30MB, triển khai qua uvicorn + ngrok
