Neural Voice Console

Built a fully local, multilingual speech-to-text and translation pipeline. No cloud, no API keys, no ongoing costs — just open-source models on my own machine. Stack: FastAPI backend + custom HTML/CSS/JS frontend, using HuggingFace Whisper for transcription (Vietnamese, English, German).

  • Fine-tuned a LoRA adapter on ~4,000 Vietnamese audio samples (6.5 hrs of speech) — boosted accuracy from 87.4% to 94.3%, adapter just 18MB (vs. 1.5GB base model)

Why it matters: proves I can build a production-quality AI voice pipeline that's fully offline, privacy-safe, and $0 to run — real for anyone handling sensitive data or working with limited API budgets.
