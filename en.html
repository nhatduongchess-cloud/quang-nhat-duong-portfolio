Flagship

CARLA ADAS — Level 3 Active Safety & Autonomous Driving

2026 · Solo · Python / PyTorch / CARLA

An end-to-end autonomous-driving pipeline in the CARLA simulator: multi-sensor perception → sensor fusion → a committed active-safety arbiter, wrapped in an L3-style ODD/MRM layer and a safety-capped reinforcement-learning cruise controller. Built geometry-first and test-driven.

  • Perception: YOLOv8/v10 (FP16) + LiDAR clustering (DBSCAN) + lane detection + Kalman tracking; LiDAR→camera fusion for true metric range.
  • Calibration-free LiDAR braking corridor — brakes for any in-path obstacle whether or not YOLO labels it. A missed detection cannot cause a missed brake.
  • L3 framework: ODD monitor + minimal-risk maneuver (TOR→MRM→SAFE_STOP); a DQN cruise controller held under a hard safety cap.
  • Found & fixed a collision-causing bug, then locked it with 179 simulator-free regression checks on GitHub Actions CI.
Committed active-safety arbiter
NORMAL→ FOLLOW→ EVADE→ EMERGENCY_BRAKE

A committed state machine with hysteresis — no brake↔evade oscillation, and geometry always overrides the learned components.
